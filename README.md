# 雪街书咖

一间可以推门走上伦敦雪街的咖啡书店。打开 `index.html` 就坐在窗边。点击咖啡杯可以喝咖啡，点击诗集可阅读和翻页。首次互动会开启声音。

推门上街后，手机可在屏幕左下方按住并滑动来行走，同时用右手滑动转头。转向的手势是左滑左转，右滑右转，上滑抬头，下滑低头。停在街上和坐在店里也用同一套方向。电脑用 WASD 或方向键移动，拖动鼠标环顾。可从斑马线走到对街，点店门或「回咖啡店」返回座位。

项目自带 Three.js r170 和音频，可离线打开。修改 `src/` 后运行 `python3 build.py` 重新生成项目根目录的独立网页和线上版本清单。音乐为项目所有者提供的第二首录音。环境录音署名见 `assets/CREDITS.txt`，Three.js 许可见 `vendor/LICENSE`。
